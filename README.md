# Machine Learning Portfolio

Educational machine learning projects developed with Python and scikit-learn, focused on model evaluation and generalization.

| Project | Focus | Recorded result |
| --- | --- | --- |
| [Bike Sharing Demand Prediction](bike-sharing-demand/) | Regression, chronological validation, baseline comparison | 62.1% reduction in validation MAE vs. baseline |
| [Classification Experiments](classification-experiments/) | MNIST augmentation, Titanic feature engineering and classification | 83.39% exploratory CV accuracy with XGBoost on Titanic |

Each project includes a Jupyter notebook and a README explaining the methodology, results, reproduction steps and limitations. These are study projects, not production deployments.

The notebooks retain their experimental outputs. The Titanic archive extraction cell has a small security-related adjustment; the experiments have not been rerun for publication.
